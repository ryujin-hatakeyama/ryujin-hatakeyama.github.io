# Projects

Project records are Markdown files with YAML front matter. The current collection is intentionally empty. Non-draft records appear on the Research page; the body is reserved for future project pages and is not currently published.

```yaml
---
slug: stable-slug
title: Project title
summary: Verified project summary
status: active
links: []
draft: true
---
```

Allowed statuses are `active`, `completed`, and `paused`. Optional localized fields are `titleJa` and `summaryJa`.
